    A NOTE ABOUT THIS FIRST VERSION

    Your notes stay yours.

    With a Groq API key configured, StudyBuddy uses Groq for lessons, quizzes, image analysis, and assessments. Module names and section headings become context for focused lessons; each bullet and each comma-separated subtopic becomes its own lesson, up to 500 topics per plan. Each lesson page is generated only when selected, with up to 250 output tokens per lesson and model reasoning disabled to reserve tokens for the explanation. Lesson pages give a concise explanation and example. Quizzes contain multiple-choice questions based on completed lesson topics, followed by an applied scenario in multiple-choice format. Choose a question count or include all topics. Each answer includes an explanation. Missed answers appear below the quiz results with your answer, the correct answer, and an option to get another focused explanation. Model availability and account limits apply.

    Lesson requests send the selected topic part, follow-up explanation requests send that topic's notes and the learner's question and missed-answer details, quiz requests send lesson summaries, and image requests send the image to Groq; StudyBuddy does not save those requests. Image analysis adapts to visible content such as text, flowcharts, diagrams, charts, people, and objects, describing their labels, actions, and relationships while marking uncertain details. AI explanations can still be wrong: compare important details with your source material and trusted references. Without a Groq API key, StudyBuddy can read visible text from an image but cannot interpret diagrams or other visual content. Supported image formats include PNG, JPEG, WebP, and GIF; other formats are converted in your browser when possible.

    Lessons and quiz explanations include a related verbatim passage from your notes when a match is found; use it to check the explanation, not as a guarantee that every claim is supported. Study readiness is an estimate based on checked topics, and untested topics lower the estimate. Lesson pages can be read aloud in English by your browser and printed or saved as a PDF. The save indicator shows when progress is saved and offers a retry if saving fails.
